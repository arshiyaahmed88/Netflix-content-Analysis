# Netflix Content Analysis

An analysis of 8,790 Netflix titles, completed as part of a Business Analytics internship.

## Tools
Excel (COUNTIF, PivotTables, charts) and Tableau Public

## Key Findings
- 70% of titles are movies and 30% are TV shows
- India stands out as a strong market for expansion
- Most content targets adults, so there is room for more kids' series
- Releases peaked in 2018, with 1,146 titles
